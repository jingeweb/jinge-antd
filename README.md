# Jinge + Tailwind + TypeScript + Vite

这个最小化模板项目集成了以下功能：

- [jinge](<>) web 框架。
- [tailwindcss](<>)。
- typescript(tsx)。
- vite 打包器。
- eslint 最新版配置，prettier 格式化。
- husky + lint-staged。

## 使用

```bash
git clone https://github.com/jingeweb/jinge-starter
cd jinge-starter
pnpm i
pnpm dev # 启动研发
# pnpm build # 构建项目
```
